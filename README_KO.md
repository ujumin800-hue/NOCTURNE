# NOCTURNE 무료 웹앱

## 실행 및 배포
이 폴더의 파일을 GitHub 저장소 루트에 업로드한 뒤 GitHub Pages를 활성화하면 HTTPS 주소로 사용할 수 있습니다.
1. GitHub에서 새 Public repository 생성
2. 이 ZIP을 풀고 안의 파일을 저장소 최상위에 업로드
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` 선택
4. 생성된 HTTPS 주소를 iPhone/iPad Safari에서 열기
5. 공유 버튼 → 홈 화면에 추가

## 기능
- 기기에서 선택한 오디오 파일 재생
- 재생/일시정지/이전/다음/셔플/탐색
- Media Session을 통한 지원 기기의 잠금 화면 제어
- 가사 직접 입력(현재 페이지 세션 내 보관)

## 제한
- 이 버전은 YouTube 오디오를 가져오거나 추출하지 않습니다. YouTube는 별도 사이트로 엽니다.
- PWA의 잠금 화면 백그라운드 재생은 iOS 버전/브라우저 상태에 따라 제한될 수 있으며 네이티브 앱처럼 보장되지 않습니다.
- 브라우저 저장소에 음악 파일을 영구 보관하지 않습니다. 페이지를 다시 열면 파일을 다시 선택해야 할 수 있습니다.
- 가사는 현재 세션 동안만 보관됩니다.
- HTTPS 호스팅이 필요합니다.
